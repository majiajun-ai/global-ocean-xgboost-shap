# Global Ocean Ecological Risk Prediction

## Overview

A large-scale machine learning framework for global ocean ecological risk prediction using XGBoost and SHAP.

## Highlights

- 476 million samples
- 14 environmental features
- Global 0.25° spatiotemporal dataset
- Explainable machine learning


## Methodology


Data:
- Satellite observations
- Ocean environmental variables


Model:
- XGBoost
- Imbalanced learning
- Early stopping


Interpretation:
- SHAP feature importance
- Regional-year attribution analysis


## Results

Independent test:

- AUC-ROC: 0.896
- AUC-PR: 0.462
